# Roadmap

The active milestone is **Windows↔macOS screen sharing and attended control**, with optional microphone audio. Camera calls are removed. Android delivery is deferred while its native capture/accessibility/lifecycle source remains available.

| Area | Completion target |
|---|---|
| Rooms | One-click creation, invitation entry, native links, removal and invitation lock/rotation |
| Screen | Measured 1440p motion/detail on direct and encoded fallback, bounded queues and actual diagnostics |
| Internet | Blocked-P2P fallback, visible budget failure and physical different-network desktop tests |
| macOS | Apple Silicon package plus actual capture/microphone/input/TCC behavior |
| Input | Harmless editor tests, reliable revoke/expiry/teardown and Mac modifiers; broader layouts later |
| Voice | Audible bidirectional checks, restart, output selection and Bluetooth |
| Delivery | Matched desktop artifacts, hashes/source/test boundaries; signing/notarization separately |
| Android later | Physical iQOO background/routing/orientation and native encoder improvements |

Free workers.dev coordination removes the domain purchase requirement. Smooth high-resolution screens still need efficient encoding and a reachable media path. GitHub source and online badges do not supply unlimited relay bandwidth.

The JPEG compatibility path does not satisfy high quality. Encoded fallback needs actual decoded moving-content dimensions/frame rate, sound and consented input. Same-PC forced-fallback proof is separate from endpoints on different networks/countries.

TURN stays optional/disabled until provider-enforced free quota and credential expiry are verified. No paid plan, card or automatic overage is part of development. Larger groups, host migration, unrestricted phone input, recording, messages and files remain outside this milestone.

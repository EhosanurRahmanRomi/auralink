# Roadmap

| Area | Next work |
|---|---|
| Media | Hardware/Bluetooth tests, native Android WebRTC encoder, adaptive motion/detail |
| Connectivity | Explicit TURN configuration, reachability diagnostics, IPv6/cross-network testing |
| Input | More keyboard layouts/Unicode, improved Android gestures/text, multiple displays |
| Delivery | Windows signing, Apple Developer notarization, verified update delivery |
| Security | Independent review, persistent authenticated identities, lifecycle/parser testing |
| Rooms | Accessibility, reconnection and host migration; larger groups after measurements |

Paid signing or relays are optional future distribution choices. Developing these local test builds requires no paid API. Global discovery and reliable worldwide connectivity need coordination and reachability infrastructure.
